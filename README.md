# Portfolio - Omar Sena

Portafolio personal y presentación profesional de Omar Sena, desarrollado como una experiencia web inmersiva con estilo cyberpunk, animaciones y una interfaz interactiva para mostrar proyectos, experiencia y contacto.

## Vista previa

![Preview del portfolio](assets/img/portfolio_preview_1.webp)

## Características

- Diseño moderno y visualmente impactante
- Animaciones y efectos interactivos
- Sección de presentación personal
- Showcase de proyectos
- Información de experiencia y habilidades
- Formulario de contacto

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript vanilla
- GSAP
- Three.js
- ScrollTrigger

## Ejecutar localmente

1. Clona este repositorio.
2. Abre la carpeta del proyecto.
3. Inicia un servidor local desde la raíz:

```bash
python3 -m http.server 8000
```

4. Abre tu navegador en:

```text
http://localhost:8000
```

## Construcción opcional

Si deseas generar una versión optimizada del sitio, puedes ejecutar:

```bash
npm install
npm run build
```
